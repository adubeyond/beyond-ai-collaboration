# BEYOND 最小示例

这是一个零第三方依赖的 Node.js 小项目，用于体验 BEYOND 3.0 的项目接手、完整任务、开发、测试和证据收口。

初始项目只提供一个`add(left, right)`函数和一个测试。推荐任务是在不引入其他功能或依赖的前提下增加`subtract(left, right)`及其测试。

## 环境

- Node.js 18 或更高版本。
- 不需要运行`npm install`。

## 初始验证

```text
npm test
npm run check
```

初始预期：一个测试通过，源码和测试语法检查通过，不生成`node_modules`和锁文件。

## 导入协同模板

从仓库的`模板交付包/`复制以下内容到本目录：

```text
AGENTS.md
docs/AI编程协同机制/
skills/
```

保留本文件作为示例项目自己的`README.md`。完整操作和第一个任务提示见[快速开始](../../docs/快速开始.md)。

## 示例边界

- 本示例只验证本地文件、Node.js 内置测试和项目文档闭环。
- 不需要第三方依赖、数据库、网络、服务器或生产环境。
- 不提供 Git、部署或数据操作授权。
- 运行后的项目事实属于临时演示目录，不应写回本仓库原始示例。

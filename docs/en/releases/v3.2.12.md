# BEYOND 3.2.12: three native CLI helpers, one goal loop

The Desktop Worker route remains the default. Optional Codex, ZCode, and Claude Code helpers share the existing task, result, review, and retained-session lifecycle.

- Real visible native terminals, tool progress, and same-session continuation.
- Serialized notifications per owner, checking the latest foreground turn before delivery rather than interrupting ongoing work.
- Task-private model and effort choices on start/resume; change configuration after a run ends and is reviewed, without mutating shared defaults.
- Explicitly authorized unattended permission modes, without overriding business scope, OS permissions, directory trust, or provider entitlements.
- Fixes for a process-exit race, native ZCode setting parameters, and preservation of redacted upstream errors.

The six Skills, Desktop callback/receipt protocol, business states, and model matrix are unchanged. No permanent service, third-party CLI installation, credentials, or local profiles are shipped.

Native testing covers Codex 0.162.0-alpha.2, community zcode-app-cli 3.14.4-32, and Claude Code 2.1.294. ZCode/Claude use version-specific private integration points and remain opt-in experimental adapters, not arbitrary-version compatibility guarantees.

Upgrade from the official 3.2.11 baseline after preserving any local hotfixes or customizations. See the [validation evidence](../../releases/v3.2.12-validation.md) and [upgrade instructions](../../releases/v3.2.12-install.md). Package publication and installation are separate actions.

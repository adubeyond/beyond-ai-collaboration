# BEYOND v3.1.3 Upgrade Guide

> Comparison: `v3.1.2 → v3.1.3`. This patch removes the Codex Hook dependency from the standard runtime without changing the PM, Worker, three-state, Action Skill, Git, test, or release paths.

## Why upgrade

The v3.1.1–v3.1.2 identity Hook required separate trust, runtime probes, tool-name compatibility, and restarts. In some Codex Desktop environments these control steps blocked installation, PM takeover, or formal Worker creation. v3.1.3 returns identity and task control to BEYOND's explicit entries and task relationships.

## Changes

- Standard installation, initialization, PM takeover, and verification no longer install or depend on a BEYOND Hook.
- PM and Worker identity follows explicit Skills, the current user-visible task, and its source relationship.
- Installation verification checks the entry, six Skills, release manifest, and project fusion directly. It does not require Hook trust, runtime probes, or a mandatory restart.
- Existing-project upgrades remove only legacy BEYOND handlers that reference `beyond-runtime-guard.mjs` and known BEYOND runtime state. Other Hooks, `.codex` configuration, and unrecognized same-name files are preserved.
- Project-local `beyond-control/` remains the default. An external shared control repository remains an explicit user choice.

## Verification

- Static implementation-path, installation-integrity, legacy-entry migration, team-control, public-content, and Git-diff checks passed.
- All 71 real Codex cases completed with exit code 0 in an isolated environment without enabling Hooks.
- The complete PM dispatch, Worker code/test/local-commit, terminal callback, and PM closeout path passed 24/24 assertions.

## Upgrade

Follow the [Installation, Upgrade, and Project Initialization Guide](../../../模板交付包/docs/en/installation-upgrade-and-project-initialization.md) for the target release and existing-project adoption. Affected files are backed up before precise migration. There is no need to enter `/hooks` or restart Codex solely for a BEYOND Hook.

# BEYOND 3.2.6 stable release

This release promotes the validated R3 build without rebuilding it. Download `BEYOND-3.2.6-R3.zip`; the product version is 3.2.6 and R3 identifies the preserved build. Projects already using this exact build do not need to reinstall. Previous releases remain available.

## Changes

- A PM can own a whole project or an explicitly delegated scope while retaining project-wide understanding and technical judgment. Existing cross-task coordination supports handoffs without adding another controller.
- With explicit project approval, Workers can use the tested sweet-spot model combinations and switch complete combinations at natural continuation boundaries. Existing approvals, running tasks and PM settings are not silently changed.
- Preserve native callbacks, short-lived receipts, acceptance and acknowledgement. The existing bounded wait of up to one minute does not treat elapsed time as completion evidence.
- Add one exact local-record read when a local registered Worker turn has completed but normal task interfaces still provide no final text. Validate thread, directory, latest turn and completed final; reject stale, mismatched, incomplete or conflicting records. Recovered text is evidence, not automatic acceptance or new authorization.
- Install only listed product and Skill files, preserving project state, history, shared registrations and business content. The external checksum file is optional.

## Install and verify

Follow `INSTALL.md` inside the release ZIP. Its manifest lists 64 product files. Back up only affected targets; preserve `local/`, `projects/`, `shared/` and `.git/`. Verify installation and restart Codex without starting or restoring business tasks.

The R3 build passed 23 reader assertions, two actual-record replays and eight isolated model behavior cases. Packaging also passed 44 upgrade-preservation checks and 52 installation regression checks. Model transport was simulated, not a substitute for all Desktop environments or long-running production tests.

Post-install use has shown successful local final recovery and follow-up handling. The fallback still depends on the local record format, does not support remote records and cannot guarantee callback delivery or uninterrupted project advancement. Long conversations may still require renewed checks of goals, authorization and current project instructions. This release adds no context-reread reminder and includes none of the latest behavioral experiment scripts.

Build-time reports inside the unchanged ZIP describe its pre-publication state; the Release page records publication.

# BEYOND v3.2.1 Upgrade Guide

> Comparison: `v3.2.0 → v3.2.1`. This is a terminal-closeout and adoption-backup patch. It does not change the 3.2 identities, three business states, task model, or control-plane architecture.

## Fixes

1. A Worker finishes every business tool and site-changing process and drafts its complete final before making the lightweight wakeup its last tool call. After the wakeup it can only emit the final and end.
2. A callback no longer proves that the Worker has ended. A running Worker without a readable final stays in progress; an explicitly ended turn without a readable final becomes one recoverable pause instead of being accepted early, polled indefinitely, or replaced.
3. Missing startup, release, repair, or verification work stays with the original Worker when it is still part of the same business result.
4. Project inspection and local-state backup skip `.codex-pytest`, `.pytest-tmp`, `.pytest_cache`, and `.beyond-local-backups`, preventing generated test sites or historical backups from being recursively scanned and copied.

## Unchanged guarantees

- The formal Worker final remains the only task-result truth; a callback only wakes the PM.
- One user-visible Worker continuously owns one business result, using only `进行中 / 已暂停 / 已完成` as business states.
- No Hook, notify adapter, background process, extra Codex CLI, worktree, or persistent result inbox is added.
- Project identity and workbench changes remain deterministic 3.2 runtime actions.

## Upgrade

Stop active PM and Worker tasks. Replace the project-local `beyond-control/` and six user Skills from the immutable `v3.2.1` package, fuse the project `AGENTS.md`, and restart Codex. Run installation-integrity verification, then verify one normally completed Worker and one genuinely paused Worker.

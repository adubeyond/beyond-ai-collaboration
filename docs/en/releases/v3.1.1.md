# BEYOND v3.1.1 Upgrade Guide

> Comparison: `v3.1.0 → v3.1.1`. This patch repairs installation and existing-project adoption without changing the normal PM → Worker → terminal-return path.

## Fixes

- Full installation verification now requires a real `PreToolUse` runtime probe; file-only comparison is explicitly reported as `--content-only` verification.
- Hook trust uses `/hooks` from Codex CLI started at the project root, not an unverified Desktop menu.
- Existing-project inspection prioritizes formal documents, excludes generated/temp trees, and identifies nested repositories, duplicate remotes, and legacy workbenches.
- Active legacy tasks require explicit adoption into the local workbench; completed items are compacted into history instead of being silently replaced by an empty mainline.
- Existing `AGENTS.md`, Hook configuration, and guard files receive byte-exact backups before fusion.

## Acceptance boundary

Installation is complete only when all six Skills match, the fused project entry is complete, Hook files match, and `hook-probe` has produced evidence bound to the current project and runtime-file hashes.

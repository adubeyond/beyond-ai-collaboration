# BEYOND v3.1.4 Upgrade Guide

> Comparison: `v3.1.3 → v3.1.4`. This is a documentation-consistency patch. It does not change the v3.1.3 PM, Worker, Skill, initialization, Git, test, or release mechanisms.

## Fixes

- The Quick Start no longer ties installation of the six Skills to a mandatory Codex restart. Restart only when the current client demonstrably retains stale Skill content.
- The English Quick Start no longer claims that project initialization installs an identity guard. Legacy migration removes only the BEYOND guard and preserves third-party Hooks.
- The bilingual home pages, documentation indexes, runtime marker, and release manifest now identify `v3.1.4` consistently.

Continue to use the [Installation, Upgrade, and Project Initialization Guide](../../../模板交付包/docs/en/installation-upgrade-and-project-initialization.md) for installation, upgrades, and existing-project adoption.

# BEYOND 4.0.0 CLI 完整候选 R1（2026-10-16）

制品标识：`BEYOND-4.0.0-CLI-CANDIDATE-R1-20261016`。这是在已发布 4.0.0 上继续修补的完整候选，不是增量包，不是新的正式发布，不覆盖原正式包。产品内部版本仍为 4.0.0；以包内 buildId、来源提交和内容清单区分本候选。

## 包含的改动

- 保留 4.0 的任务与工程文档分离、业务规格与技术设计、资料读取与维护机制，以及已有三种 CLI 兼容修补和负责人移交。
- 每轮 CLI 明确阶段交付，同时保留完整目标；新要求可保存并按现有审查与续跑路径接续，避免在旧要求下无边界扩展。
- Codex、Claude Code、ZCode 读取当前任务对应的需求、设计和必要 Skill，原会话继续时刷新适用资料，不用旧聊天替代当前文档。
- Codex 程序路径按当前可用程序解析，既有活跃进程仍使用已经绑定的程序，不因公共路径变化迁移运行中的任务。
- Windows 新启动的受管 CLI 管理进程验证独立于调用宿主的关闭作业；调用端退出后已派发工作可继续，重新接入时读取原结果、续用原会话。

新增产品脚本 `cli-context.mjs`、`codex-executable.mjs`、`manager-launch.mjs` 均包含在完整产品清单中，配套回归脚本留在 Git 源码中。

## 已知问题与能力边界

1. `gemini-4-argon`：三种 CLI 的真实调用均遇到第三方网关 HTTP 503；其中明确报模型通道 `channel_info` JSON 解析失败。本候选不修复上游服务，不能宣称 Gemini 可用或续聊通过。
2. `glm-5.3-flash-codex`：本次网关不接受 Codex 的 `medium` 请求；本机原生默认配置与公共启动 profile 调整为 `low` 后，默认启动、读文件和当前 BEYOND 所选 CLI 的同会话续聊通过。该调整仅属于本机公共配置，不随通用包分发，不修改模型矩阵。其他电脑需按服务商实际支持值配置；已有任务保存的显式配置不会被批量改写。
3. npm Codex CLI 0.160.1 有一次独立测试会话续聊等待 150 秒未返回，未算通过；原因尚未确定。当前 BEYOND 解析到的 Codex CLI 0.163.0-alpha.10.2 完成了对应续聊。不同程序的结果不互相替代，也不据此固定 CLI 版本白名单。
4. 宿主关闭测试使用自有隔离 Windows Job，并未关闭用户正在运行的桌面端。真实模型的读资料、工具调用和同会话续跑另行验证，不冒充生产环境端到端验收。
5. 独立生命周期只适用于由新入口启动的管理进程，不自动迁移已有运行进程；不保证操作系统注销、关机、重启或手工关闭原生 CLI 后继续工作。桌面离线期间结果仍保存，但没有新增通知补发或自动唤醒机制。

## 未改变的部分

桌面 Worker 回调、通知协议和模型矩阵不变；不接管或恢复现有任务，不改原会话及成果，不附带项目资料、凭据、第三方模型目录或本机私有配置。本次只构建候选，不安装、不推送、不发布。

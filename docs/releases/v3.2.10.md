# BEYOND 3.2.10：可见的原生 CLI 对话

本版把已验证的第三方 API 原生 Codex CLI 路径纳入可选执行分支：看得到执行过程，保留同一会话，实际执行回合结束后通知负责人，核验后继续原会话。默认 Desktop Worker、回执和PM回源协议保持不变；模型矩阵沿用3.2.9。

## 新增能力

- Windows可自动打开独立原生终端，显示真正的Codex交互界面，不把JSON日志包装成聊天。Linux可在用户自己的终端attach同一会话。
- PM直接使用CLI或原Worker调用CLI，两条路径沿用现有负责人、任务记录及验收入口。派单后不陪跑；通知是本轮结果，不是业务完成。
- 程序续派与原生窗口输入都绑定同一个sessionId。普通部分完成、纠偏和补充不另起会话；窗口退出后可以恢复原会话。
- 原生模式在服务、会话及每轮派单设置完全访问、不弹逐命令审批。实际动作仍不得超出用户对业务、文件、Git、服务器和生产的授权。
- 本机连接仅监听127.0.0.1并使用短期认证token。认证仍在CLI专用CODEX_HOME，不复用Desktop登录，不把密钥放进产品、命令行或结果。

已有未设置mode的CLI配置继续使用原exec日志模式；不自动更改已有任务。启用原生模式需要Node.js 24及支持认证app-server的Codex可执行文件，当前实测0.160.0。上游WebSocket仍为实验接口，本版不是对所有第三方模型、CLI版本或宿主唤醒行为的保证。

安装仍保留项目资料、工作台、历史、pending及Git；不自动安装CLI、写入凭据或启动业务任务。详见[安装与升级](v3.2.10-install.md)、[验证与限制](v3.2.10-validation.md)及[CLI使用说明](../../模板交付包/docs/AI编程协同机制/机制/04-CLI目标协作机制.md)。

# BEYOND v3.1.4 升级说明

> 对比范围：`v3.1.3 → v3.1.4`。这是文档一致性补丁，不改变3.1.3的PM、Worker、Skill、初始化、Git、测试或发布机制。

- 快速开始不再把安装六个Skill与强制重启Codex绑定；只有当前客户端明确仍缓存旧Skill时才重启。
- 英文快速开始不再宣称项目初始化会安装身份护栏，并明确旧项目迁移只精确移除BEYOND旧护栏、保留第三方Hook。
- 中英文首页、文档索引、运行版本和发布清单统一为`v3.1.4`。

安装、升级和老项目初始化继续使用[安装、升级与项目初始化指南](../../模板交付包/docs/安装升级与项目初始化指南.md)。

# BEYOND 4.0.1 HF-20261020 完整维护候选

这是完整候选 `BEYOND-4.0.1-HF-20261020`，不是增量包，也不替换远端正式版本。目标是修正多对话通信中的授权误读、事实更新遗漏和过早清除回执，同时保留已经使用的 CLI 修补。

## 本轮内容

- 外部助手的转述不能自行扩大老板授权；原有正式 PM 纠偏、Worker 回报及已授权协作仍然可用，不增加审批层。
- 每轮 CLI 上下文明确实际项目、任务与负责人，不能把原生 CLI 内同名成员误认成桌面负责人。这是上下文纠正，不宣称建立工具级跨会话隔离。
- 已核实且改变判断的事实归位到原任务和主线；不续派不等于不更新，明确只读和重复事实仍不写入，不自动恢复任务。
- 终态回执只有在相应工作台事务确已提交后才能清除。保留原回传顺序、身份校验和业务状态；未提交或事务不匹配时保留回执。
- 说明 Codex 单路派发、回传和同会话接续用法，并澄清原生窗口手输续跑不是 PM 验收。
- 保留 Claude 目录兼容、等待问题提醒、空闲管理器退出和既有已验收目标恢复兼容；不改变现有会话、模型或权限配置。

## 组合边界

本候选从已核实源码及现用兼容修补组成独立、可追溯的打包分支。开发工作区另有未纳入此前候选的新目标 `sessionFrom` 改造，本包不包含该改造及对应说明，也不删除或改写开发工作区的未完成成果。现有 `acceptedGoalRecovery` 兼容按原字节保留并单独回测。

没有修改模型矩阵、桌面通知传输、通知时序、业务代码或项目资料。不新增定时器，不强停、重建或自动恢复业务任务。运行中的旧管理器不会因磁盘安装自动热加载。

参见[验证与限制](v4.0.1-hf-20261020-validation.md)和[安装说明](v4.0.1-hf-20261020-install.md)。

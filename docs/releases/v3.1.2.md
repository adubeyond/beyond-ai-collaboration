# BEYOND v3.1.2 升级说明

> 对比范围：`v3.1.1 → v3.1.2`。本补丁修正控制仓默认位置，不改变 PM、Worker、三态、Action Skill、Git、测试和发布主链。

安装、Hook信任、新项目初始化、老项目接入以及PM接手的完整操作顺序和可复制提示词，统一见[安装、升级与项目初始化指南](../../模板交付包/docs/安装升级与项目初始化指南.md)。

## 修复内容

- 默认把独立`beyond-control/`建立在当前项目根下，不再擅自放到项目平级目录。
- 只有用户明确要求多个完全独立项目共用一个控制仓时，才使用外置路径。
- 项目内初始化立即把`/beyond-control/`和`/.beyond-local-backups/`加入项目根`.gitignore`，避免独立控制仓或本机备份被误暂存为业务代码。
- 项目扫描自动排除自身控制仓，避免把 BEYOND 文档和控制仓Git误判为业务项目内容。
- Windows短路径与长路径统一后再判断项目根、控制仓和Git根。
- 项目内与外置两种模式使用同一套入口融合、Hook和安装验真。

## 默认目录

```text
业务项目/
├─ beyond-control/
├─ AGENTS.md
├─ .codex/
└─ <原有代码与文档>
```

交付包不会散着覆盖业务项目。已有`AGENTS.md`与Hook仍先备份再融合；项目文档仍按用户确认迁入、登记或暂不处理。

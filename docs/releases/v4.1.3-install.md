# BEYOND 4.1.3 安装与升级

使用完整发行包 `BEYOND-4.1.3.zip`，按包内清单和发行附件核对内容。外置 `.zip.sha256` 可选；提供但不匹配时停止。本版发布不自动安装到任何项目。

相对 4.1.2，产品只变更 `skills/identity-product/SKILL.md`、根入口的版本标记和发行版本清单；运行时及其他 Skill 内容不变。安装仍使用既有完整包路径，不以单独覆盖或混用版本代替验真。

确认目标项目、共享 Skill 使用范围与必要维护空档，保存实际改动对象的精确前像。保留项目资料、配置、Git、未提交代码、工作台、原 CLI 会话、模型设置、历史结果和成果，不用空模板覆盖业务资料。按现有融合入口更新并执行安装验真，不擅自停止或恢复任务。

磁盘文件更新不代表已有对话已重新读取。需要继续的对话应重新读取当前原型设计规则；若启动时加载的规则仍旧，按平台实际加载方式在安全时机新开对话或重启，不擅自重建 CLI 会话。

回退仅恢复本次精确前像，不能整树覆盖后来成果。完整命令与维护边界见[安装、升级与项目初始化指南](../../模板交付包/docs/安装升级与项目初始化指南.md)。另见[版本说明](v4.1.3.md)和[验证范围](v4.1.3-validation.md)。

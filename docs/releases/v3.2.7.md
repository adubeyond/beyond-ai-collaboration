# BEYOND 3.2.7 正式版

这次更新聚焦模型选择与任务收口可靠性，保留一个 PM 总管或多个 PM 分管、原执行者连续交付、项目背景按需读取和授权边界。不是重做协作流程，也不引入新的后台调度器。

## 改了什么

- **GPT-6 模型策略。** 新启用 `beyond-worker-gpt6-v3` 时，重复处理从 Luna/high 开始，常规开发、设计和高后果任务从 Sol/high 开始，综合推理难题从 Astra/low 开始。PM 可在已批准范围同时选择模型与强度：Luna high/max，Sol high/xhigh/max/ultra，Astra low/ultra。旧 v1/v2 批准不自动替换；用户当轮明确指定优先于默认值，正在运行的执行者不被强制打断。
- **回调先到不等于执行者开启了新一轮。** PM 根据回合编号区分“正在结束的本轮”和“已经开始的后续回合”，保留最长一分钟的有界核对和严格限定的本机补读，处理后继续未答完的用户问题。
- **长对话仍能补读正式结果。** 本机读取器流式处理固定文件快照，不因文件整体超过 256 MiB 就拒绝读取。线程、目录、当前回合、结束证据、内容一致性及读中变更检查仍然保留。
- **并发回执不会被旧确认误删。** 同项目同任务的回执替换与确认互斥，比较回执编号和删除处于同一次受保护操作中，不将不同任务全部串行。列表读取允许其他 PM 同时确认删除回执；损坏或权限错误仍明确报错。
- **已验收历史可补清理回执。** 操作缓存被长期活动挤出后，仍可凭相互一致的持久事务和唯一历史记录判断已提交；有缺失或矛盾就保留，不重复验收。
- **批准记录校验一致。** 使用策略与安装验真都拒绝无效时间或非文本批准依据，不再出现一边接受、另一边拒绝。

## 安装与升级

下载本 Release 的 `BEYOND-3.2.7.zip`，按包内 `INSTALL.md` 操作。`.sha256` 为可选校验文件，缺失不阻断安装；已提供但不一致时停止。包内清单与安装后内容验证必须通过。

仅替换清单内产品文件和六个对应 Skills，融合项目根入口，保留项目原生规则、`local/`、`projects/`、`shared/`、`.git/` 和业务内容。升级不启动、恢复或关闭业务任务。替换全局 Skills 后重启 Codex。

## 验证范围与限制

发布验证包含真实 runtime 的隔离状态事务、跨进程并发、缓存淘汰、坏记录拒绝、模型策略、长记录读取、升级保留，以及真实模型驱动的隔离 PM 行为。详细结果见 [验证记录](v3.2.7-validation.md)。

模型行为测试使用模拟任务传输、真实产品运行内核，不冒充 Desktop 平台消息送达测试。当前宿主工具声明支持的模型参数，不代表每个账户或未来宿主都支持；切换请求被接受不等于已经核实实际执行配置。本版没有自动安装到生产项目，也不承诺消除所有长上下文漂移、平台漏唤醒或模型判断错误。

没有引入 Laya/Jev、Hook、notify、守护进程或额外 CLI。

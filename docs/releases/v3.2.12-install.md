# BEYOND 3.2.12 安装与升级

这是可选 CLI 能力升级，不创建或恢复业务任务。项目根不必是 Git 仓库。

1. 确认实际项目根、控制仓、用户 Skill 目录；活动 Worker、CLI 或 PM 操作尚未结束时，不中途替换它们正在使用的规则。
2. 校验 ZIP 内清单：文件集合、字节数与哈希。外置 .sha256 可选；已提供但不匹配时停止，缺少它不阻断包内核验。
3. 与官方 3.2.11 及实际安装内容比较。保留本地热修复和项目定制；发现范围外差异时先确认，不静默回退。
4. 为本次覆盖的产品文件、六个 Skill、根 AGENTS 及固定融合涉及的登记/忽略文件保留新鲜可回退前像。无需复制无关历史缓存或业务仓。
5. 只按包内清单替换产品内容；保留 local、projects、shared、.git、CLI 会话、第三方认证及业务文件。六个 Skill 沿用 3.2.11 内容，不引入 PM 规则草稿。
6. 执行固定融合与完整验真：

   ```text
   node <controlRoot>/scripts/beyond-control.mjs install-project-entry --project-root <projectRoot> --confirm-fusion yes
   node <controlRoot>/scripts/verify-install-integrity.mjs --installed-skills-root <skillsRoot> --project-agents <projectRoot>/AGENTS.md
   ```

7. 完全退出并重启 Codex；重启后确认实际项目身份与运行版本，再继续业务工作。安装不派单、不恢复旧任务、不改桌面模型或平台审批配置。

可选 CLI 使用本机已有安装和独立认证。默认 Desktop Worker 路径保持不变；已有 Codex 配置继续兼容，ZCode/Claude 需显式指定 provider 和当前支持版本。完全访问须有用户授权；不要通过安装流程静默放宽第三方全局设置或绕过系统权限。详细配置见包内 beyond-control/docs/AI编程协同机制/机制/04-CLI目标协作机制.md。

回退恢复本次精确备份；安装后已有业务或用户修改时先核对冲突，不覆盖新成果。包内 TEST-RESULTS.md 区分真实模型验证、隔离验证和未验证边界。

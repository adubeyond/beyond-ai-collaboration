## 不外推的结论

- 程序隔离测试不冒充真实桌面自动唤醒；真实样本也不证明长时间稳定性或所有上游版本兼容。
- 派发配置记录证明请求参数，不保证第三方服务实际使用同名底层模型或推理预算。
- 六个 Skill、桌面 Worker 终态协议及模型策略不变；工作台只增加可选正式 CLI 任务负责人移交，不改变业务状态或默认 Worker 路径。
- ZCode/Claude 的可见终端接口包含指定版本私有实现。公开 CI 的跨平台隔离测试不等于在 Linux 上真实启动这些 Windows 适配器。
- 完成回归、生成包、真实安装、重启加载及公开发布分别核验，不相互替代。

# 4.0.1 HF-20261018-R2 安装说明

使用完整包 `BEYOND-4.0.1-HF-20261018-R2.zip`。以包内 release/content manifest 确认候选身份、来源和全部文件；外置 SHA-256 可选，包内清单与安装验真必须通过。不得用旧 HF 包替代本候选。

1. 安装前核对目标项目 PM、Worker、CLI 的当前执行轮、待接续请求及进程身份，并核对共享 Skill 的其他消费者。等待任务自然结束后的安全空档，不用旧工作台状态或桌面回合结束代替 CLI 静止证据，不为升级强停、恢复或重建任务。
2. 计算实际覆盖清单，为这些产品文件、共享 Skill 和必要入口制作可验证的精确前像，记录新增路径原先不存在。不复制整个业务仓或缓存；不覆盖或清理 `local/`、`projects/`、`shared/`、业务 `.git/`、业务代码、配置、会话、结果、审查记录和其他成果。
3. 正式写入前再次核对安全空档和前像未变化，再按候选清单更新产品与受影响 Skill。根入口已经一致时保留原字节；确需融合时保留项目覆盖和原生规则。不得修改工作台来制造任务完成或安装空档。
4. 对解压内容和安装结果逐文件验真，运行本包 `verify-install-integrity.mjs` 检查实际用户 Skill 根与项目入口，并复核会话、成果及其他保护对象未改变。记录本次安装的实际范围、验证结果与回退入口。
5. 规则刷新等待用户在安全时机重启，不自动关闭应用或恢复任务。磁盘更新不会让存活的旧 CLI 管理器热加载代码；以进程实际加载来源核对生效状态，不为让新修复立刻生效而强停原管理器或重建执行会话。

回退只恢复本次覆盖对象。若安装后产生了新成果或配置变化，先核对再回退，不整树覆盖项目。具体原则见[安装升级指南](../../模板交付包/docs/安装升级与项目初始化指南.md)；本次身份和范围以本说明及包内清单为准。

安装成功只证明候选已按清单落地，不代表业务任务完成、旧通知已经补发或生产自动推进已验收。本候选不发布到远端发行渠道。

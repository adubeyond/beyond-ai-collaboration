# BEYOND 3.2.8

发布日期：2026-10-02。

本版把模型策略收敛为一套 GPT-6.1 矩阵，并加入可选 CLI 目标协作；原生 Desktop Worker 的回传、暂停恢复和验收协议保持不变。

## 模型选择

常规开发、修复、文档和一般方案以 6.1 Sol 中为起点；逻辑较多可选高，精细完整 UI、跨模块设计、矛盾分析可选超高。规则明确的提取、转换与重复处理由 Luna 低或高承担。架构难题、复杂排障和关键判断考虑 Astra 中，必要时提高。

优先完成度和总速度，再考虑包含返工的总成本。PM 在同一 Worker 的正常续接点按任务选择模型与强度，不跨模型继承强度、不强制试遍低档、不打断正在执行的工作。

正式运行选项只有当前矩阵与平台默认。旧矩阵留在 Git 历史；旧配置仅用于升级识别，明确启用新矩阵前，新建保留平台默认、续接不重置原线程，不把历史批准解释为新授权。

这些是官方建议与产品判断形成的起点，不是跨模型性能排名或固定节省比例。[官方模型选择指南](https://developers.openai.com/api/docs/guides/model-selection)。

## 可选 CLI 路径

支持 PM → Worker → CLI，以及 PM 或 Worker直接与CLI协作。指定项目、配置和授权，保留 CLI 会话；每轮结束后通知负责人，负责人检查结果并指导原会话继续或验收，而不是持续陪跑。

直接 CLI 任务使用独立记录和验收；经 Worker 调用时仍由该 Worker 交付。通知与进程结束不等于业务完成。CLI 凭据和第三方模型由本机显式配置提供，安装包不附带密钥，也不自动安装 CLI 或常驻服务。

## 修复与兼容

- 修复未标版本旧入口迁移时覆盖区重复嵌套，保留原生规则与非模型覆盖。
- 修复 Windows 等价路径格式导致的 CLI 执行位置误拒绝。
- 保留非 Git 项目、单仓、多仓、已有工作树、并发回执、暂停恢复、幂等验收及项目事实读取。
- 安装保留 `local/**`、`projects/**`、`shared/**`、`.git/**`；不自动处理既有任务。

实际测试范围、结果与限制见[发布验证记录](v3.2.8-validation.md)。模拟结果不等于真实宿主送达保证；本版不宣称所有平台永不漏通知或第三方 API 与原生模型等价。

# BEYOND v3.1.1 升级说明

> 对比范围：`v3.1.0 → v3.1.1`。本补丁修复安装与老项目接入，不改变普通 PM→Worker→完成回传主链。

## 修复内容

- 完整安装验真必须包含真实`PreToolUse`运行探针；文件一致只能用`--content-only`声明为内容核对。
- Hook信任统一走项目根目录 Codex CLI的`/hooks`，不再指向无法确认的桌面菜单。
- 老项目检查优先正式文档，排除临时和构建目录，并识别子仓库、重复remote和旧工作台。
- 旧工作台有活动任务时显式迁入本机工作台，已完成项进入历史；不再静默建立空主线。
- 融合前对原`AGENTS.md`、Hook配置和护栏脚本做字节级备份。

## 验收边界

安装完成必须同时满足：六个 Skill与候选一致、项目入口融合完整、Hook文件一致、`hook-probe`已生成与当前项目和文件哈希绑定的证据。任何一项缺失都不能宣布升级成功。

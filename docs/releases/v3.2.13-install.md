# BEYOND 3.2.13 安装与升级

这是包含控制仓、六个 Skill、软件工程资料及现有 CLI 修补的完整包，不依赖此前的增量包。项目根不必是 Git 仓库。安装本身不创建、恢复或续派业务任务。

1. 确认实际项目根、控制仓和用户 Skill 根。正在使用相关规则的 Worker、CLI 或 PM 操作应先按用户安排结束或停用，不在安装中擅自暂停或恢复任务。
2. 核对包内清单的文件集合、字节数与 SHA-256，以及发布版本和来源。外置 `.sha256` 文件可选；缺少它不阻断包内核验，已提供但不匹配时停止。
3. 对照目标当前产品内容。保留已有 CLI 热修复和项目定制，不能因为版本号相同就覆盖差异；目标存在本包未包含的更新时先核对，避免回退。项目正文以原所有者为准，不用通用模板替换业务资料。
4. 为本次覆盖的产品文件、六个官方 Skill、根 `AGENTS.md` 和固定融合涉及的登记、忽略文件保存新鲜前像，并列明安装前不存在的文件。无需复制无关历史缓存或业务仓。固定入口内部的范围文件前像不等于整项目或 Git 的自动回滚备份。
5. 仅按产品清单更新控制仓，不删除整个目录。保留 `.git/`、`local/`、`projects/`、`shared/`、任务、pending、CLI 会话、第三方认证、业务文件及其他非产品文件。六个官方 Skill 分别备份后精确更新，其他用户 Skill 不动。
6. 执行既有固定入口融合，不直接覆盖业务项目根 `AGENTS.md`：

   ```text
   node <controlRoot>/scripts/beyond-control.mjs install-project-entry --project-root <projectRoot> --confirm-fusion yes
   node <packageRoot>/beyond-control/scripts/verify-install-integrity.mjs --installed-skills-root <skillsRoot> --project-agents <projectRoot>/AGENTS.md
   ```

   验真器取自本次完整包，核对实际安装目标；同时按内容清单复核产品文件。固定融合会更新自身登记、备份和忽略规则，不应改变既有任务、pending、CLI 会话、业务事实、自有 Hook 或认证。
7. 验真通过后完全退出并重启 Codex，再确认实际项目身份、运行版本及资料入口。安装不更改桌面模型、平台审批、第三方全局权限或回调机制。

## 已有项目怎样使用新资料

不需要重新初始化所有文档或迁移目录。由 PM 从原项目总览与事实索引重新读取当前主事实；已有正文只补缺失入口和必要引用，过期说明先核对来源后纠正。执行者沿当前任务及直接依赖补读，核实的新知识在已有授权内维护到原正文。

当前不需要的资料可以保留为未整理、待核对或不适用，不以填满模板作为开工条件，也不自动恢复旧任务。使用方法见[工程资料指南](../../模板交付包/docs/AI编程协同机制/工程资料指南.md)。

## 回退与边界

回退使用本次安装保存的精确前像，只移除安装前不存在的本次新增文件；已有后续用户或业务改动时先处理冲突，不整树覆盖新成果。内部 `project-preimage` 用于范围文件恢复，不能交给整目录 `restore-local` 冒充完整备份。

可选 CLI 继续使用本机已有安装和独立认证，不因升级自动启用或获得生产权限。本版不承诺兼容任意后续第三方 CLI 版本；相关边界见[验证说明](v3.2.13-validation.md)。

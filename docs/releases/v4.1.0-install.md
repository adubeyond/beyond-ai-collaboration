# BEYOND 4.1.0 安装与升级

使用完整发行包 `BEYOND-4.1.0.zip`。发布不等于已安装；每个已有项目分别确认维护范围和安全空档，不强停、迁移或恢复业务任务。

1. 确认目标项目根、控制仓与共享 Skill 的实际使用者。正在执行的对话或 CLI 不因发布被停止；安装前按已获授权范围留出安全空档。
2. 核对完整包的版本、来源提交、内容清单和发行附件。外置 SHA-256 文件可选；已提供但不一致时停止，未提供也必须完成包内及安装验真。
3. 只为本轮实际覆盖对象保存精确前像；保留业务代码、数据、配置、Git、项目资料、工作台、待处理结果、CLI 会话和历史成果。不要复制整个业务仓和缓存，也不要用空模板覆盖项目资料。
4. 按清单更新通用产品并安装七个 Skill：`identity-pm`、`identity-product`、`identity-worker`、`task-design`、`task-dev`、`task-test`、`task-ops`。复用已有事实入口与工程文档，不要求重新初始化全部业务。
5. 通过现有融合入口更新项目根规则，运行完整安装验真。共享 Skill 更新后在安全时机重启 Codex 并核对加载版本；磁盘安装不证明已有会话已重新读取新规则。
6. 原 CLI 会话、模型、结果和审查记录保持原样。新职责和交付契约不自动迁移旧任务，也不授予恢复执行或发布业务的权限。

回退使用本次精确前像，仅恢复本轮实际覆盖对象；之后新增的业务成果和会话记录不能被整树覆盖。不要混用旧版 Skill 与新版产品文件。

完整命令和维护提示词见[安装、升级与项目初始化指南](../../模板交付包/docs/安装升级与项目初始化指南.md)。另见[版本说明](v4.1.0.md)及[验证与限制](v4.1.0-validation.md)。

# BEYOND 4.0.0 验证与边界

记录日期：2026-10-15。验证绑定本版完整候选，不把以往局部绿色结果拼成整包通过。

## 验证范围

- 文档与任务两套职责、读取入口和真实链接/章节；新旧项目索引初始化、登记、保留原资料及引用重定位。
- PM 对多轮无进展的实质分析、执行者按原目标回报、跨任务资料复用；局部过期标注与有效设计保留。静态契约及变异断言不冒充模型必然遵守。
- Claude 可执行文件失败、版本变化、同会话恢复及原消息通道；ZCode 版本/无关源码变化、真实接入点、伪锚点拒绝、能力失败的具体错误保留。
- 既有三 CLI 会话、错误、通知、竞争、恢复及负责人交接回归；冻结检查继续保护回调、工作台状态和模型策略，仅接纳本次精确批准的兼容修补。
- 完整包清单、解压内容验真、从上一正式版升级并精确回退，保留业务资料、任务、pending 与 CLI 会话字节。
- GitHub Windows 与 Ubuntu 的公开验证，分别作为跨平台证据。

## 发布门禁与证据解释

本版发布须通过完整产品隔离回归、公开内容检查、干净已提交源码打包、升级回退检查及公开 CI。实际结果以本版 PR 检查、发行附件的来源提交和验真记录为准；未通过不得发布。

独立复审发现的测试入口遗漏，以及 ZCode 接入前能力拒绝未进入既有错误文件的问题，已修复并补入回归。跨入 4.0 时还发现旧验真器把发行版本硬限定为 3.x.x；现已把发行版本与数据格式分开，仍要求原 schemaVersion=3，不改变运行协议。双语安装指南和快速开始也同步到本版，避免从新版入口下载旧包。

修正后的专项安装完整性 100/100、团队控制仓 66/66、设计/冻结边界 16/16 通过；安装专项包含 11 个版本与 schema 正反例。完整候选仍必须重新执行全部 27 组隔离回归和上述发行门禁，不能用专项通过替代。首轮因版本格式限制失败的证据保留，不改写成通过。

本版没有增加第二条回调、偷偷切换会话或重刷整个保护基线。

## 不冒充的结论

隔离夹具和文档路径检查不证明任意业务都能完整交付；合成 API/本地传输不证明第三方网关的实际模型身份或付费服务质量。没有启动新的真实桌面 PM/Worker 或操作现有业务会话，也不把本机原生源码预检当成生产 CLI 全链验收。

本次发布不包含真实项目安装。安装、重启后加载和实际业务验收仍需在目标项目分别核对。未来上游接口不兼容仍会明确失败，不能保证仅因移除版本白名单就永远可用。

# BEYOND 3.2.11 安装与升级

这是产品升级，不创建或恢复业务任务。项目根不必是Git仓库。

本完整包的升级基线是官方3.2.10。若现场另有未发布热修复或项目自定义的控制仓代码，不能仅凭版本号相同就整包覆盖；先对齐差异并保留这些补丁。本版未把某个项目的爬虫修复流程或其他本地扩展并入通用产品，也未验证这些定制组合的升级。

1. 确认真实项目根、控制仓及Codex用户Skill目录；等待活动任务结束，不打断正在运行的Worker或CLI。
2. 解压ZIP并验证包内清单的集合、字节与哈希。外置.sha256可选；已提供但不匹配则停止。
3. 为本次替换的产品文件、六个Skill、根AGENTS及固定融合实际涉及的登记/忽略文件制作新鲜可回退前像。不要求备份无关历史缓存。
4. 按清单覆盖产品文件和六个同名Skill，保留local、projects、shared及.git，不覆盖业务代码、凭据或运行状态。
5. 执行固定融合和完整验真：

   ```text
   node <controlRoot>/scripts/beyond-control.mjs install-project-entry --project-root <projectRoot> --confirm-fusion yes
   node <controlRoot>/scripts/verify-install-integrity.mjs --installed-skills-root <skillsRoot> --project-agents <projectRoot>/AGENTS.md
   ```

6. 完全退出并重启Codex；安装本身不派单、不恢复业务任务，不改桌面模型、审批设置或既有任务身份。

本版不要求启用CLI。原有可选CLI配置与认证继续保留；默认Desktop Worker路径不变。升级前后分别核对运行版本与六个Skill，文件更新不等于旧对话已重新加载规则。

# BEYOND 4.1.1：结果收取与原生后台通知修补

4.1.1 是基于 4.1.0 的窄范围修复，仍以完整发行包交付，不是增量覆盖包。它修补内部助手结果收取和 Claude 原生后台通知的边界，不重写协作职责、正式 Worker 回调或模型矩阵。旧版发行资产保持原样；发布不自动安装到任何项目。

## 修复什么

- **内部助手先收取再结束。** 本回合承诺的交付依赖内部助手时，启动者先收取并核验必要结果；可以等待原生完成事件，不轮询过程。父回合结束后，不假定助手完成会自动开启新回合。确需跨回合自动接续时，只使用已经获准的 CLI 或正式任务路径，不自动迁移助手、补建任务；用户当前问题、暂停和检查点优先。
- **识别同轮 Claude 原生后台结果。** 从当前已接受指令之后的结构化工具调用与结果建立任务关联，限定当前会话和项目；处理首次 Stop 之前到达的完成通知和新会话转录文件稍后建立的情形。历史、异会话、异项目、重复、未配对或夹带额外命令的通知不能据此获得接续权限。
- **等待与完成分开。** 已完成、失败或停止的后台记录不再单独造成无限等待；未知后台状态、观察不可用和会话定时任务等待负责人处理，通过已有的直接负责人提醒路径报告。提醒与正式结果分开，不自行形成成功或失败终态。
- **保留权限边界。** 提醒仍经过现有忙碌保护和串行通知，不代替用户授权，不执行定时提示，不恢复暂停任务，也不自动验收。此补丁没有增加常驻调度器。

## 保留什么

正式 Worker 的终态回执、原生回调、PM 收口和派单后不陪跑规则不变。既有 CLI 会话、同会话接续、模型配置与矩阵、结果、审查和历史成果保持原样；不因补丁自动停止、重建或迁移会话。

完整包仍包含七个 Skill。安装需另有目标项目授权和安全维护空档；共享 Skill 更新后按既有流程重启 Codex 并验真。磁盘更新不证明已运行的会话或 CLI 管理进程热加载了新内容。

## 证据与边界

隔离检查覆盖当前轮关联、提前通知、转录观察、反例拒绝、提醒与终态分离、忙碌负责人通知，以及既有 CLI 和正式 Worker 路径。测试中的模型与 Desktop 对端是模拟实现，不是真实模型到 Desktop 的在线端到端验证，也不证明内部助手在父回合结束后必然唤醒它。

完整验证按 32 组入口执行；实际通过、失败、源码快照和包验真结果以对应发行资产中的 `BEYOND-4.1.1.validation.json` 及包清单为准。本页不把待执行的检查预写为通过。

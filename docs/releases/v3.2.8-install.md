# BEYOND 3.2.8 安装与升级

这是产品安装维护，不创建 PM、Worker 或业务任务。

1. 确认实际项目根与 Codex 用户 Skill 根。项目根不必是 Git 仓库。
2. 解压 ZIP，验证包内清单的文件集合、字节数与哈希。外置 `.sha256` 可选，缺失不阻断；提供但不匹配时停止。
3. 为本次实际替换的产品文件、六个用户 Skill、根 `AGENTS.md` 制作可回退前像。不以不受影响的历史缓存权限作为安装门禁。
4. 按清单覆盖产品文件，精确替换六个同名 Skill。保留 `local/`、`projects/`、`shared/`、`.git/`，不递归用空模板替换整个控制仓，不改业务代码或凭据。
5. 通过目标控制仓固定入口融合并验真：

   ```text
   node <目标控制仓>/scripts/beyond-control.mjs install-project-entry --project-root <实际项目根> --confirm-fusion yes
   node <目标控制仓>/scripts/verify-install-integrity.mjs --installed-skills-root <实际用户Skill根> --project-agents <实际项目根>/AGENTS.md
   ```

6. 安装后停止，重启 Codex。旧模型记录可识别，但旧矩阵不再执行；用户明确启用当前矩阵或选择平台默认，不自动更改原线程模型或恢复旧任务。

替换入口和 Skills 前等待活动任务停止，不强行打断工作。发生差异先说明真实原因，不扩大安装范围。CLI 协作为可选分支，只使用已经配置的本机 CLI；不自动安装 CLI、认证、Hook 或常驻服务。详见包内安装指南和 `beyond-control/docs/AI编程协同机制/机制/04-CLI目标协作机制.md`。

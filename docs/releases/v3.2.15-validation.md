# BEYOND 3.2.15 验证与边界

记录日期：2026-10-14。本版针对辅助 CLI 负责人移交，使用临时隔离项目和进程夹具验证；不把程序测试当成真实 CLI 服务端会话交接或业务交付证明。

## 已完成的候选验证

- CLI 相邻回归 11 组、149/149 项通过；移交专项合计 41 项，其中新增 19 项辅助移交场景。
- 辅助任务保持 `assist`，不创建或修改工作台登记；任务、原会话、模型配置、契约、历轮结果和旧审查保留。
- 新负责人必须独立审查才能续跑同一会话；旧负责人控制请求被拒绝。正常正式任务的既有移交用例继续通过。
- 缺少授权来源、调用者不符、状态或结果变化、模式冲突、批量辅助移交、活动进程或无法验证的进程状态均不能被当作成功移交。
- 覆盖重复请求、不同目标竞争、多个持久化阶段中断后的恢复，以及新负责人续跑或再次交接后对旧请求的幂等返回。
- 独立子进程真实退出并留下任务锁时，两方均不能绕过锁继续；核实原进程已退出且状态匹配后，沿既有锁恢复与移交事务继续。持久化阶段故障注入与真实进程退出是不同证据，分别覆盖，不互相冒充。
- 独立代码复审未发现本次范围内新的确定性缺陷；审查不是无缺陷保证，也不代替测试。
- 原设计冻结校验仍保留原始基线，仅为本次获准的三个 CLI 产品文件登记精确前后指纹；回退、额外内容、缺失文件和范围外回调变化仍被拒绝。相关静态与变异检查 14/14 通过，不以重刷基线或跳过断言掩盖改动。

## 发布门禁

以下项目由本轮发布流程分别执行，不能仅凭上述 149 项候选测试判定已完成：

1. 完整产品隔离回归、公开内容与链接检查、既有保护范围核对。
2. 从干净、已提交源码生成完整 ZIP；核验清单、解压安装内容，以及相对上一正式版的升级和精确回退。
3. GitHub Windows 与 Ubuntu 公开 CI、维护者审查与批准。

实际通过结果以本版本公开 PR 检查和发行附件验真记录为准。任何必要门禁未通过都不能发布；不拿本地 Windows 结果替代跨平台 CI，不声称未执行的真实环境测试。

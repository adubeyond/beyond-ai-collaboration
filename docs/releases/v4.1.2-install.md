# BEYOND 4.1.2 安装与升级

使用完整发行包 `BEYOND-4.1.2.zip`，不要混用旧版产品与新版 Skill。发布不等于已安装；每个项目分别确认安装授权、维护范围和安全空档，不因发布强停、迁移或恢复业务任务。

1. 确认目标项目根、控制仓与七个共享 Skill 的实际使用者。活动对话和 CLI 按既有授权与检查点处理，不扩大停止或恢复权限。
2. 核对版本、来源提交、包内清单和发行附件。外置 `.zip.sha256` 可选；提供但不匹配时停止，未提供仍须完成包内内容和最终安装验真。公开附件 `BEYOND-4.1.2.validation.json` 包含验证摘要，不代替目标项目安装验真；构建者另保留本地 `.zip.verification.json`。
3. 为实际覆盖或融合的对象保存精确前像，记录原先不存在的新路径。保留业务代码、配置、Git、项目资料、工作台、回执、CLI 会话、模型设置、结果和审查记录；不备份整个业务仓或用空模板覆盖资料。
4. 按完整包清单更新产品文件及匹配的七个 Skill：`identity-pm`、`identity-product`、`identity-worker`、`task-design`、`task-dev`、`task-test`、`task-ops`。复用既有文档与项目登记，不创建新任务或迁移会话。
5. 使用既有融合入口更新项目根规则并运行安装验真。根入口或共享 Skill 更新后，在安全时机按既有流程重启 Codex，核对实际加载版本；不能把磁盘更新当成已有会话已重读规则，不为应用补丁擅自重启或重建 CLI。
6. 分开报告安装验真、规则实际加载和业务验收。本版不改变审批或安全设置，不取消平台拒绝，也不改变正式 Worker 回调、运行时和模型矩阵。

回退只恢复本次精确前像中的覆盖对象，并精确处理原先不存在的产品路径；不得整树覆盖后来新增的业务成果、会话或项目状态。

完整命令与维护提示词见[安装、升级与项目初始化指南](../../模板交付包/docs/安装升级与项目初始化指南.md)。另见[版本说明](v4.1.2.md)和[验证范围与限制](v4.1.2-validation.md)。

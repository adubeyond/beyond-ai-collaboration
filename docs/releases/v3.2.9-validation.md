发布包包含 71 个产品文件和 6 个元数据文件。隔离升级用例以 3.2.8 标签为基线，覆盖原生业务规则、活动与暂停任务、pending、控制仓 Git 和旧 v4 策略记录：安装不得丢失这些对象，也不得把旧审批直接解释为 v5；回退必须逐文件恢复到安装前相同字节。

## 发布包检查

`scripts/build-release.mjs` 只从干净、已提交源码构建；记录源提交和产品树，拒绝覆盖已有发行物，重新打开 ZIP 校验 CRC、精确文件集合、字节数与 SHA-256，并对实际解压内容执行产品验真。外置 `.sha256` 仍为可选，不用其缺失阻断安装。

`node scripts/check-release-package.mjs <实际解压根>` 进一步从 Git 的 v3.2.7 建立非 Git 业务项目，保留原生入口、历史模型批准、进行中/暂停任务及 pending，检查清单升级、六个 Skill、入口融合、旧批准不重解释及按前像逐字节回退。检查只写独立临时目录，不安装或恢复生产任务。

已对提交 `a99c263` 构建的候选包执行：71 个产品文件、77 个 ZIP 文件全部校验通过，实际解压内容验真退出码 0。升级检查通过，31 个受保护文件在产品覆盖时保持不变，任务状态未改变，入口原生规则保留，旧批准没有自动启用新矩阵，回退后的全部文件哈希与前像一致。正式包仍从最终干净提交重新构建并重复包检查，而非复用含未提交改动的 ZIP。

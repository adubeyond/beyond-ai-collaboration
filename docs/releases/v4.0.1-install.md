# BEYOND 4.0.1 安装与升级

使用完整包 `BEYOND-4.0.1.zip`。发布不自动安装，已有项目的安装应在授权维护窗口单独执行。

1. 确认项目根、控制仓、用户 Skill 根以及正在运行的任务和 CLI。不为安装擅自停止、恢复或转移任务。
2. 核对包内 manifest：版本 4.0.1、buildId、来源提交、产品树、文件清单。外置 SHA-256 文件可选；没有它仍继续包内验真，若已提供但不一致则停止。
3. 为实际覆盖的产品文件、六个 Skill、融合入口和登记对象保存新鲜精确前像；保留原业务代码、数据、配置、Git、`local/**`、`projects/**`、`shared/**`、工作台、pending、CLI 会话及成果。不把整个业务仓和缓存复制为备份。
4. 按清单更新通用产品，保留合法项目定制；使用 `install-project-entry` 融合入口，并用本包 `verify-install-integrity.mjs` 核验实际安装对象。现有工程资料直接复用，不要求重新初始化。
5. 升级后刷新桌面规则加载，核对项目身份与 4.0.1 内核；不自动恢复历史任务。独立生命周期能力只用于新入口启动的管理进程，不迁移旧进程。

本包不包含本机第三方认证、模型目录和启动 profile，也不自动将其他电脑的 GLM 强度改为 low。按服务商支持值配置，不批量改写原任务的模型或强度。

回退使用本次精确前像，只恢复实际覆盖对象；保留原会话、独有成果和之后产生的变化，不整树覆盖。

详细步骤见[安装指南](../../模板交付包/docs/安装升级与项目初始化指南.md)。参见[版本说明](v4.0.1.md)和[验证与限制](v4.0.1-validation.md)。

# BEYOND 3.2.9：Sol 优先模型矩阵

发布日期：2026-10-02。此补丁调整模型策略，不改回传、任务推进、忙碌前台保护或可选 CLI 协议。3.2.8 的标签和安装包保留不变。

发布验证同时发现并修复 Windows 锁目录交接时的短暂读取拒绝：复用既有有界文件重试，持续权限错误仍报错，不改变锁归属或回执协议。

## 默认分布

| 用途 | 模型与推理强度 |
| --- | --- |
| PM | GPT-6.1 Sol · xhigh（极高），由用户在平台设置 |
| 常规开发、修复、文档、一般设计 | GPT-6.1 Sol · high（高） |
| 复杂设计、困难排障、关键判断 | GPT-6.1 Sol · xhigh（极高） |
| 规则明确的分类、提取、重复批量处理 | GPT-6 Luna · high（高） |
| 明确需要的攻坚 | Astra，由 PM 结合证据明确选择 |

这些是结合用户实测反馈制定的起点，不是官方性能或额度保证。先保证交付完整度和速度，再衡量总消耗；不能仅凭通用榜单将困难任务降档。

## 选择与迁移

当前唯一可执行策略为 `beyond-worker-gpt61-v5`；v5 是策略标识，不是产品版本。新项目仍须由用户明确启用策略，或保留平台默认。旧 v4 等审批记录只用于识别迁移，不被静默改写为新矩阵；选择新策略后才应用新默认。

PM 不自动更改自身模型，也不批量重配已有任务。用户明确锁定模型时遵守锁定；同一 Worker 可随任务阶段调整，每次明确传入模型与推理强度并核对平台实际可用组合。一般先在 Sol 高与极高间判断，需要攻坚时再明确选择 Astra，而不是按类别默认使用 Astra。

升级保留根入口中的原生业务规则、项目事实、工作台、历史、pending 和既有控制仓 Git。外置 SHA-256 文件仍为可选；包内清单与安装验真必做。

验证范围与限制见 [3.2.9 验证说明](v3.2.9-validation.md)，安装步骤见 [安装与升级](v3.2.9-install.md)。

# BEYOND 3.2.11：把进展推进到结果

本版只调整PM和Worker对非终态进展的判断：局部交付后还有已授权工作就继续；只剩真实依赖就说明等待条件，不反复发送“收到、继续”；新事实和依赖解除仍须及时推进。

## 本次变化

- Worker交出一部分成果或收到协作确认后，回到原任务剩余结果。依赖只阻塞受影响动作，不把其他安全工作一起停掉。
- PM不根据“进行中”三个字机械续派。区分仍可执行、只剩依赖、重复确认、用户检查点和已经接续，必要时给原Worker明确的下一动作。
- 同一结果的重复转述可合并；不同任务、新故障和刚解除的依赖不能丢。必要交接与本轮进展只回报一次，不制造确认往返。
- 收到回调仍保留当前用户问题。处理必要结果后继续原请求，不追着刚续派的Worker等确认，也不等所有后台任务完成才回答。
- 当前进度写清剩余结果、实际动作、等待责任方与条件。“进行中”不等于进程仍在执行。

## 保留的机制

原Worker、终态回调、短期回执、验收、暂停恢复和模型矩阵均保留。没有新增任务状态、消息队列或调度器，也没有把原业务目标缩小为阶段目标。CLI执行与通知实现沿用3.2.10，本版不夹带未发布的CLI实验改动。

这些规则改善的是智能体的判断依据，不是平台消息送达保证。真实模型对照、程序回归和未覆盖边界分别记在[验证报告](v3.2.11-validation.md)。安装仍保留项目资料、工作台、历史和pending，见[安装与升级](v3.2.11-install.md)。

升级适用官方3.2.10基线。有额外本地热修复或项目定制代码的安装须先保留并对齐差异，不能用本完整包直接覆盖这些扩展。本轮发布不等于向已有生产项目安装。

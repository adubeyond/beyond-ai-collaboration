# BEYOND 4.0.0 安装与升级

使用完整 `BEYOND-4.0.0.zip`，不需要叠加旧候选或增量包。项目根无需是 Git 仓库。安装与业务恢复、真实 CLI 移交分别授权，不因版本升级自动继续历史任务。

1. 核对真实项目根、控制仓、用户 Skill 根及相关 PM、Worker、CLI 的活动状态，避免覆盖正在使用的实现；不擅自终止任务。
2. 核验包内清单、文件集合、字节数、SHA-256 和来源版本。外置 `.sha256` 文件可选，缺少不阻挡包内验证；已经提供但不匹配则停止。
3. 比对现有产品定制及 CLI 修补，只为实际覆盖的产品文件、六个 Skill、融合入口和登记对象保存新鲜前像，记录原来不存在的对象。不要复制业务仓、缓存或历史副本作为安装备份。
4. 按清单更新产品，不整树重建。保留项目原有业务/工程资料、`.git/`、`local/`、`projects/`、`shared/`、工作台、pending、CLI 任务与会话、历轮结果、审查、认证及其他非产品内容；其他用户 Skill 不动。
5. 使用既有融合与验真入口：

   ```text
   node <controlRoot>/scripts/beyond-control.mjs install-project-entry --project-root <projectRoot> --confirm-fusion yes
   node <packageRoot>/beyond-control/scripts/verify-install-integrity.mjs --installed-skills-root <skillsRoot> --project-agents <projectRoot>/AGENTS.md
   ```

   验真器来自本次包，同时核对实际目标和应保留状态；只看到版本号一致不能代替内容验真。
6. 完全退出并重启 Codex，刷新已加载入口。已有 PM 重读新版入口、项目总览与资料索引及受影响正文；新 PM 按正式接手链了解当前全貌。复用已有正式资料，只修正失效入口或补当前任务真正需要的缺口，不重新初始化、全量搬迁或重批仍有效设计。

## 回退

按本次精确前像恢复实际覆盖对象，仅删除本次新建且没有后续变化的文件。保留独有改动、项目资料、CLI 状态及必要恢复材料；发现后续变化先处理冲突，不整树覆盖。

本版不改变桌面回调、模型矩阵和既有会话协议。安装不等于原项目业务已验收，也不保证未来任意 CLI 私有接口都兼容。

参见[版本说明](v4.0.0.md)和[验证与边界](v4.0.0-validation.md)。

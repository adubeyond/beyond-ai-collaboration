# 4.0.1 HF-20261018 安装说明

使用完整包 `BEYOND-4.0.1-HF-20261018.zip`，以包内 release/content manifest 确认候选身份、来源提交及全部文件。外置 SHA-256 可选，包内清单与安装验真必须通过。

1. 核对目标项目原 PM、Worker、CLI 的当前轮和待接续请求。等待安全空档，不以桌面回合结束或旧工作台状态代替 CLI 实际退出；不得为安装擅自停止、恢复或重建会话。
2. 核对六个用户 Skill 的共享影响。只备份实际覆盖的产品、Skill 和必要入口，记录新增路径原先不存在。保留项目资料、业务代码、配置、Git、工作台、pending、会话和成果；不要复制整个业务仓或缓存。
3. 按清单更新产品和六个 Skill；既有根入口已经与候选一致时保留原字节，否则按固定入口融合并保留项目覆盖。正式安装前再次检查空档和前像未变化。
4. 运行本包 `verify-install-integrity.mjs` 对实际用户 Skill 根和项目 AGENTS 验真；逐文件核对产品清单，同时复核会话和保护对象未改变。安装不代表业务任务完成，不修改工作台来制造完成状态。
5. Skill 更新后需刷新 Codex 规则加载；等待用户在安全时机重启，不自动关闭正在工作的应用。重启后核对原项目与会话，不自动恢复任务。

回退只恢复本次覆盖对象；遇到安装后新增成果或配置变化先核对，不整树回滚。具体安装原则见[安装升级指南](../../模板交付包/docs/安装升级与项目初始化指南.md)，本次候选身份以本说明和包内清单为准，不另行下载旧正式包替代。

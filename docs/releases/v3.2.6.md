# BEYOND 3.2.6 正式版

本次正式发布采用已安装核验的 R3 构建，下载包为 `BEYOND-3.2.6-R3.zip`。产品版本为 3.2.6；R3 标识本次保留的构建来源，不需要已使用同一构建的项目重复安装。此前候选和历史版本保持不变。

## 本版变化

- PM 可按用户委托负责整个项目或分管明确范围，保留项目全貌、技术判断和原执行者连续交付；跨线接力复用现有机制，不新增总控层。
- 经项目明确批准，可采用模型甜品位组合，并在原执行者自然续接点按工作难度切换完整组合；不自动改变 PM 配置、正在执行的任务或旧授权。
- 保留原生回调、短期回执、验收与确认顺序。收到回传但结果尚未完整时先使用原有有界等待；最长等待一分钟不是固定睡眠，也不是完成证据。
- 本机执行者已结束、正常接口仍读不到正式正文时，增加一次精确的本地记录补读。核对线程、目录、当前回合和正式回答；拒绝旧回合、身份不符、不完整或冲突记录。补读只补证据，不代替验收、不扩大权限。
- 安装仅替换清单内产品文件和对应 Skills；保留项目状态、历史、共享登记及业务内容。外置校验文件可选，不因缺失阻断安装。

## 安装

从本版本 Release 下载 ZIP，按包内 `INSTALL.md` 操作。包内有 64 份产品文件及对应内容清单。只备份本轮受影响目标，保留 `local/`、`projects/`、`shared/` 和 `.git/`；安装并验真后重启 Codex。安装不恢复或启动业务任务。

## 验证与限制

R3 构建通过 23 项读取器断言、2 项实际记录回放、8 类隔离模型行为验证；打包时通过 44 项升级保留检查和 52 项安装回归。隔离模型使用模拟任务传输，不代表所有 Desktop 平台或长期生产负载。

安装后的实际使用已观察到补读正式结果并继续处理的成功案例，但仍依赖本机记录格式；不支持远程记录，也不承诺永不漏回传或自动推进永不失误。长对话中目标、授权和工作路径仍可能需要重新核对。本版不包含新增的上下文重读提醒或本轮对照实验脚本，不宣称已解决长上下文漂移。

ZIP 内构建报告的“未公开发布”字段描述构建时状态；公开发布状态以本次 Release 为准，原 ZIP 不重写。

# BEYOND 3.2.7 安装与升级

这是产品安装维护，不创建 PM、Worker 或业务任务。

1. 确认实际项目根与 Codex 用户 Skill 目录。项目根不必是 Git 仓库；不要把其他机器的路径照抄到本机。
2. 解压 ZIP。`.sha256` 外置文件可选；如果提供了它，先核对 ZIP 哈希。核对 `release-manifest.json` 与 `content-manifest.sha256.json`，验证文件集合、字节数和哈希，无额外载荷。
3. 在替换前为受影响的产品文件、六个 Skill 和项目根 `AGENTS.md` 制作可恢复备份。保留项目运行状态和自有资料，不要求备份与本次不受影响的历史缓存绑定。
4. 按清单将 `beyond-control/` 内产品文件覆盖到目标控制仓；不要删除或覆盖该仓的 `local/`、`projects/`、`shared/`、`.git/`，也不要递归用空模板替换整个目录。精确替换六个同名用户 Skill，不改其他 Skills 或 Codex 配置。
5. 使用目标控制仓固定入口融合根入口并验真：

   ```text
   node <目标控制仓>/scripts/beyond-control.mjs install-project-entry --project-root <实际项目根> --confirm-fusion yes
   node <目标控制仓>/scripts/verify-install-integrity.mjs --installed-skills-root <实际用户Skill根> --project-agents <实际项目根>/AGENTS.md
   ```

6. 报告结果并停止，重启 Codex 后再继续原项目。升级不更改已批准的模型策略；新策略需明确启用，不自动恢复或收口任务。

发生校验差异时说明真实原因，不猜测修复或扩展安装范围。完整方法见包内 `beyond-control/docs/安装升级与项目初始化指南.md`。不安装 Hook、notify、守护进程或额外 CLI。

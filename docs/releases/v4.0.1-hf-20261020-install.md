# HF-20261020 安装说明

使用完整包 `BEYOND-4.0.1-HF-20261020.zip`，核对包内版本、来源、清单和逐文件内容。不要用旧候选或开发目录中未纳入本包的功能替代。

1. 从目标项目实际目录核对现有版本、根入口、本地 CLI 修补和当前运行状态。后台 CLI 尚在运行或有待续时不安装；桌面空闲不能代替后台静止。共享 Skill 有其他活动消费者时也不覆盖。
2. 根据包与现场差异制定精确覆盖清单，保存每个覆盖对象的原字节和新增路径不存在的证据。保留项目原生规则、项目编号、正式路径、配置、未提交代码、业务文档以及全部任务/会话/请求/结果/审查历史，不整仓复制或覆盖。
3. 根入口采用现有受管融合方式，不能只更新控制仓模板而漏掉真实根入口，也不能把模板覆盖业务自定义区。保留现场 `acceptedGoalRecovery` 兼容链；本包没有强制迁移到新目标接续机制。
4. 写入前再核对安全状态和前像；任何漂移或未知对象停止本次安装，不修改任务状态或放松检查凑空档。更新后逐项验证产品、共享 Skill、入口与保护记录，生成真实安装收据。
5. 回退只恢复本次覆盖对象；若安装后对象又变化，先核实，不能覆盖新成果。安装不终止旧进程、不自动重启、不恢复任务；重新读取规则及旧管理器下一次授权启动的生效情况分别说明。

本包包含完整产品，但本次交付不授权升级所有项目或远端发布。具体安全边界沿用[安装升级与项目初始化指南](../../模板交付包/docs/安装升级与项目初始化指南.md)。

## 产品文档与项目文档的区别

- 本目录面向人，解释产品和使用方式。
- `模板交付包/docs/AI编程协同机制/`面向导入模板后的具体项目，承载运行规则、控制状态、项目事实和证据入口。
- 产品文档不能代替项目当前工作台、正式任务、项目事实或一手证据。
- 真实项目名称、服务器、凭据、业务数据、thread ID和动态发布状态不得写入本目录。

产品说明、双语入口、架构文档、快速开始、最小示例、Apache-2.0许可证、社区行为准则和公开贡献治理已经形成GitHub首版内容。`v3.0.0-preview.1`是首个公开预览版本；最终干净候选的本地静态门禁和全新Codex端到端验收已经通过，跨平台安装/升级/回滚与公开远端快速开始仍需持续补证，本文不会把Preview描述成Stable。

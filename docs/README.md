## 产品文档与项目文档的区别

- 本目录面向人，解释产品和使用方式。
- `模板交付包/docs/AI编程协同机制/`面向导入模板后的具体项目，承载运行规则、控制状态、项目事实和证据入口。
- 产品文档不能代替项目当前工作台、正式任务、项目事实或一手证据。
- 真实项目名称、服务器、凭据、业务数据、thread ID和动态发布状态不得写入本目录。

## 当前公开准备状态

产品说明、双语入口、架构文档、快速开始、最小示例、Apache-2.0许可证、社区行为准则和公开贡献治理已经形成GitHub公开内容。当前源码候选是`v3.1.4`；跨平台安装/升级/回滚与真实生产仍需按实际目标单独验证。

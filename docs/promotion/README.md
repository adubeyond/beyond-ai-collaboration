## 统一传播口径

一句话：

> BEYOND 让 Codex 不只完成单次回答，而是让 PM、Worker、项目事实和验收证据共同推动真实项目结果。

主要展示三个事实：

1. PM 可以派发独立任务后结束当前回合，不靠持续轮询陪跑；
2. Worker 完成或真正暂停时，结果能够回到 PM 并进入验收或恢复链；
3. 代码、测试、提交、发布和生产可用分别判断，不用一句“完成了”掩盖证据边界。

## 禁止使用的宣传表达

- 不说“永不失败”“100%自动”“适配所有平台”；
- 不把 Clone 数量当作用户数或安装量；
- 不把发布包下载量当作成功安装量；
- 不把测试通过写成已经推送、部署或生产可用；
- 不把图文动画冒充行为测试或生产运行证据；
- 不把测试专用小项目包装成大型生产客户案例。

## 发布前最小检查

- 视频和文章均指向正式版本，而不是候选 ZIP；
- 下载链接与 SHA-256 链接能从未登录浏览器打开；
- 可选证据截图隐藏本机用户名、绝对路径、Token、服务器地址和 thread ID；
- 演示中的最终状态能在工作台或线程中复核；
- 各渠道使用对应文案，不整篇复制粘贴制造广告感；
- 发布后记录时间、链接和当时的 Traffic 基线。

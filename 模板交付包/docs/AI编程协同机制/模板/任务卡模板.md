# 复杂任务主面模板

> 只在任务跨多个检查周期、需要多人恢复、独立验收，或平台任务对话不足以承载当前真值时使用。简单和普通任务以正式任务对话为任务主面，不创建本文件。
>
> 本文件控制任务，不保存设计、测试、发布或事故正文。对应内容使用唯一阶段入口，本文件只登记版本、结论和链接。多智能体公共接口按[多智能体共享运行协议](../机制/03-多智能体协同机制.md)执行。

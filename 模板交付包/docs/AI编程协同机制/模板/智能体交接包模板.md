# 智能体交接包

> 只在任务真实转交给另一实例、跨工具迁移，或接收方无法直接恢复原现场时使用。同一正式任务线程的普通暂停恢复不创建交接包。
>
> 交接包只传递相对唯一任务主面的当前差异，不复制完整任务契约。共享对象、接力和冲突按[多智能体共享运行协议](../机制/03-多智能体协同机制.md)处理。

## 1. 移交身份

| 字段 | 内容 |
| --- | --- |
| 任务 ID / 当前版本 / 执行回合 |  |
| 唯一任务主面 / 当前锚点 |  |
| 发起实例 / 接收实例或待领取 |  |
| 移交原因 / 移交时间 |  |
| 当前动作 / 检查点 |  |
| 交接包使用后去向 | 合并回任务主面后关闭 / 其他 |

接收方必须先读取任务主面当前版本。交接包不能改变目标、边界、验收、授权、检查点或共享对象所有权；这些变化必须先更新唯一任务主面。

## 2. 当前现场与变化

| 内容 | 交接时事实 |
| --- | --- |
| 自任务主面最后锚点后完成的变化 |  |
| 当前代码 / 文件 / 工作区 / 运行现场 |  |
| 当前候选或制品版本锚点 |  |
| 已取得的一手证据与位置 |  |
| 未完成动作 / 当前阻塞 |  |
| 下一步最小动作 / 停止条件 |  |
| 尚未写回任务主面的内容与原因 |  |

完整日志、测试输出、截图、样本和制品留在任务登记的证据位置；这里只给出结论和链接。

## 3. 接收核验

| 内容 | 接收结果 |
| --- | --- |
| 任务主面版本是否一致 |  |
| 实际实例、工作区与现场是否一致 |  |
| 输入、证据和未完成项是否可读取 |  |
| 共享对象或并发写入是否冲突 |  |
| 接收裁决 | 接受 / 有条件接受 / 拒绝并说明缺口 |
| 新责任实例 / 下一步 |  |

没有完成核验前，接收方不产生新的副作用。发现来源、版本、控制实例、工作区或共享写入冲突时，停止受影响动作并按协同协议回源。

## 4. 关闭与回收

接收完成后：

1. 把接收裁决、新责任实例、当前结论和下一步更新回唯一任务主面。
2. 任务主面已有的内容不从交接包复制回去，只写本次新增变化。
3. 交接包不作为持续日志；完成消费后标记关闭，不再追加。
4. 有审计保留价值时，由任务主面保留链接；停止追加、移动、删除和历史回收按[项目文档入口](../00-模板入口.md)执行。
5. 后续交接新建新包，不复用旧文件。

# 产品设计与契约基线模板

> 本模板只提供`项目事实/产品设计与契约基线.md`的可选格式，不保存当前项目事实。实际文件只记录已经由有权决定者确认或由现有产品、代码、接口、数据、设计稿和正式决策核验的跨任务稳定产品事实；候选、当前任务进度、临时取舍和待决定项留在任务主面，不把空模板复制成项目事实。

实际基线负责稳定产品流程、体验约定、业务对象语义、共享业务或交互契约入口和详细业务验收口径。项目定位、业务边界和跨任务稳定决策归项目总览；接口 schema、代码、设计稿等已有正式来源继续保有原文，本文件登记适用范围、版本、所有者、核验锚点并链接过去。

## 8. 维护与使用规则

- 首次创建前先调查现有产品、代码、数据、设计和契约；只写当前任务已经核验且确需跨任务复用的部分。
- 有权决定者负责业务语义和体验取舍；代码、接口、数据和运行结果负责说明当前现实。两者冲突时不得把任一方静默改写成另一方。
- 候选设计、待确认问题、当前任务进度、临时方案和单轮证据不进入实际基线。
- 已有正式入口和新鲜证据时只读取、刷新受影响流程、对象语义、契约入口和业务验收，不重做全量设计。
- 未知项保持未知；不会改变目标、正式契约或验收的未知可以留作实施前核对，会改变这些内容的未知必须在依赖它的开发前闭合。
- 实际基线写入授权不能推导出项目总览、正式契约、源码、测试、Git、环境或其他文件的写入授权。

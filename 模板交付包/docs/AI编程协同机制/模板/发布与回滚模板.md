# 发布与回滚模板

> 本模板只在需要部署、发布、运行检查、回滚演练或故障恢复时使用。每次实例化只承载一个发布 ID 的单次记录；它不是默认必读文件，只有任务主面、运维动作或 PM 明确指定后才展开。
>
> 本模板只提供单次发布与回滚记录格式，不定义发布授权、Worker 生命周期、PM 控制关系或事件投递。运维方法以[运维动作入口](../../../skills/task-ops/SKILL.md)为准；正式任务的暂停、恢复和回源以[执行者入口](../../../skills/identity-worker/SKILL.md)及任务契约为准；直接请求不存在的任务关系不能由本模板创建。

## 10. 维护规则

- 本模板记录发布过程和发布结果，不记录稳定服务器信息。
- 稳定环境、域名、端口、服务、环境变量边界只在获得准确路径写入授权后更新运行环境事实文件；可使用 [运行环境与服务器信息模板.md](运行环境与服务器信息模板.md) 作为格式来源。
- 本次发布、发布后巡检、故障恢复和复盘写入任务主面或任务契约登记的唯一发布/生产记录；可使用 [运维巡检与故障处理模板.md](运维巡检与故障处理模板.md) 作为格式来源，不自动另建报告。
- 本模板只登记结果与证据入口。运维结果返回选择该方法的实际控制者；正式任务的事件、任务写回和 PM 消费按身份入口与任务契约执行，直接请求直接交付，不由模板制造控制关系、写入权或事件。
- 不得只因发布模板存在就判断“可发布”；必须有真实发布对象、基线、构建、验证和回滚证据。
- 当前发布状态、实际版本、证据和下一步原位更新，不按观察轮次复制整份状态；长日志、监控明细、截图和制品正文只留在登记的证据位置。
- 发布验证完成、失败收口或回滚复验完成后，把最终结论和证据返回任务主面；稳定事实归位、停止追加和历史回收按[项目文档入口](../00-模板入口.md)执行。

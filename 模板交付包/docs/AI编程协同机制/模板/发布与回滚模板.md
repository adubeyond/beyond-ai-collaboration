# 发布与回滚模板

> 本模板只记录一次确实需要留存或跨时间恢复的发布。普通发布在正式任务线程已有完整上下文和证据时不实例化本文。稳定服务器与部署步骤归运行环境事实和runbook；本文只保存本次生产上下文、实际动作与结果。
>
> 本模板不授予生产、数据、Git、停机或回滚权限，不建立任务状态或PM审批流程。运维方法以[运维动作入口](../../../skills/task-ops/SKILL.md)为准。

# 单次巡检与事故记录模板

> 只在任务需要一次巡检、故障排查、服务恢复或事故复验时使用。一个文件只承载一个巡检或事故 ID，不保存跨事故通用手册；稳定检查与恢复步骤回到部署运行手册，环境事实回到运行环境与服务器信息。

| 字段 | 当前值 |
| --- | --- |
| 巡检或事故 ID / 类型 |  |
| 对应任务 ID / 版本 / 唯一任务主面 |  |
| 项目 / 环境 / 对象 |  |
| 发现时间 / 来源 |  |
| 当前负责人 / 决定者 |  |
| 当前状态 | 待确认 / 处理中 / 已恢复待复验 / 已关闭 / 阻塞 |
| 本记录路径 / 证据位置 |  |
| 计划归档位置 | 按[项目文档入口](../00-模板入口.md)与任务契约登记 |

| --- | --- |
| 用户或监控看到的现象 |  |
| 当前影响范围 |  |
| 最近正常时间 / 当前版本 |  |
| 已确认事实 / 未知项 |  |
| 当前停止扩散动作 |  |
| 恢复目标 / 成功标准 |  |
| 当前授权与禁止动作 |  |

服务存活不等于业务恢复；没有命令、日志、监控、页面、API 或用户确认支撑时写`待核对`。

## 2. 调查与证据

只记录能够改变判断的调查节点。完整日志、截图、回包、导出样本和监控明细进入证据位置。

| 时间 | 调查对象 / 方法 | 结果与证据 | 当前判断 / 下一步 |
| --- | --- | --- | --- |

同一检查原样重跑不新增一行；只有输入、方法、现场或结论变化时更新。

## 3. 恢复动作

| 时间 | 动作与范围 | 授权 / 风险 / 回滚 | 实际结果与证据 |
| --- | --- | --- | --- |

高风险恢复前必须明确权限、影响、停止条件和可执行回滚。取消、回滚、清理和数据修复分别授权。

## 5. 稳定事实归位与历史回收

| 内容 | 位置 / 结果 |
| --- | --- |
| 新确认的稳定环境事实 |  |
| 新确认的稳定检查或恢复步骤 |  |
| 架构或核心链路变化 |  |
| 未完成事项 / 替代入口 |  |
| 最终状态 / 关闭时间 |  |
| 实际归档位置 / 引用修正 |  |

关闭前把稳定环境事实写回运行环境入口，把可复用步骤写回部署运行手册，把架构变化交相应所有者；没有准确路径授权时只返回建议和证据，不在本记录持续积累通用手册。

最终结论和证据返回任务主面；停止追加、引用修正和历史回收按[项目文档入口](../00-模板入口.md)执行。后续巡检或事故使用新的 ID 和记录，不复用本文件。

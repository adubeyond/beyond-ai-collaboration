# 项目事实索引

本索引负责把当前任务需要的能力事实路由到唯一标准主入口，不是默认冷启动材料，也不证明下列文件已经存在、已经核验或对应运行时能力已经安装可用。是否进入本索引以及进入前的读取顺序由[项目文档入口](../00-模板入口.md)决定；本文只负责进入后的事实域选择、文件契约和维护边界。

四类对象必须分开：

- 本索引：定义每个事实域的标准主入口、所有权边界和最小维护契约。
- `../模板/`：只提供可选格式，不保存项目事实。
- 本目录中的实际事实文件：只保存当前项目经过来源核对或一手验证的事实、适用范围和刷新条件。
- 工具、Skill、服务与环境的运行时状态：由当前平台和现场验证决定，不能从索引或文件存在性推断。

“唯一标准主入口”是该事实域的稳定路由，不表示所有细节都必须复制到这里。已有正式设计、契约、代码、配置、测试、脚本或受控系统继续作为对应内容的一手真值；主入口记录适用范围、正式来源、版本或核验锚点并链接过去。一个细节只由一个位置保存原文，其他事实域只引用，不为阅读方便复制第二份。

标准路径已经确定，因此无需让用户重新设计内部文件名；但路径确定不等于文件存在、内容可信或本轮拥有创建权限。没有实际文件时如实写“尚无已登记事实文件”，再在当前任务授权和真实权限内调查当前判断所需的最小现场，不把缺文件扩大为能力不可用或整个项目必须初始化。

## 2. 按需读取

1. 进入本索引后，只根据当前工作台、项目总览、当前任务、用户点名目标或当前动作已经暴露的具体缺口选择事实域，不在这里重新执行项目接手链。
2. 先选择一个对当前判断直接负责的主入口；只有该入口随后暴露了当前判断必需的明确依赖，才顺序进入另一个事实域，不并行读取其他事实文件、全部模板或整个目录。
3. 实际文件存在时，只读取支撑当前判断所需的章节；其中事实仍需结合适用范围、核验时间和现场变化判断是否可复用。
4. 实际文件缺失时，只在当前任务读取范围和真实权限内，选择一个与当前判断直接相关的一手来源进行定点调查。用户或任务明确禁止的 Git、数据、服务、环境、服务器或其他对象不得读取；文件缺失本身不扩大调查或写入权限，也不会自动触发全套文档创建。
5. 当前工作台或项目总览已经给出直接事实且本轮不需要能力细节时，停止，不为确认索引完整而进入本目录。

## 3. 首次创建

对应标准文件尚不存在时，只有同时满足以下条件才能创建：

1. 当前业务任务确实需要跨任务复用该事实，而不是只需要一次性调查结论。
2. 当前工作台、项目总览、当前任务和已知正式入口中没有另一个有效的同域主入口；没有重复入口线索时，不为证明“绝对不存在”而扫描全仓或整个文档树。已有正式设计、契约或脚本是内容来源，不妨碍创建一个只负责路由和适用范围的事实域主入口。
3. 当前任务或用户明确授予该标准路径的项目文档写入权限；只读权限、模板约定、PM 身份或文件路径预先确定都不能替代授权。
4. 已明确使用者、适用范围、事实来源、最低核验方式和后续维护方。
5. 创建内容只覆盖当前动作已经调查和验证的部分；已有正式来源时优先链接，不复制原文。未知项保持未知，不把空模板整份复制成项目事实。
6. 已明确创建后应在项目总览登记什么，以及本轮是否另有项目总览写入授权；事实文件写入授权不能推导出项目总览写入授权。

创建项目事实文件不授予业务源码、其他文档、Git、环境、服务、服务器、生产数据、不可逆动作或外部费用权限，也不自动授予`git add/commit/push`。没有文件写入授权时，只交付已确认事实、证据、建议标准路径和尚未写回原因。

## 4. 文件内最小契约

每个实际事实文件无论采用何种格式，都必须能回答：

- 它适用于哪个项目、环境、模块、版本或业务范围；
- 本文件唯一拥有的事实是什么，哪些内容只引用其他正式来源；
- 哪些内容来自有权决定者的业务确认，哪些来自一手现场证据；
- 最近一次核验时间、核验对象和证据入口；
- 哪些变化发生后必须重新核验；
- 仍有哪些未知、例外或不可安全复用的部分；
- 谁在获得对应写入授权后维护该文件。

可选模板只提供可裁剪的格式，不是必须填满的模式，也不能改变本索引、项目总览、当前工作台或任务契约的所有权。模板中的能力状态枚举、初始化阶段、当前责任任务或动态阻塞不得复制进稳定事实文件；只选取当前事实域实际需要且已经有来源的部分。需要保存易变现场时，记录最后核验、证据和刷新触发，不把旧观测冒充当前实时状态。

稳定事实可以跨任务复用，直到命中明确刷新触发；版本、分支、环境、服务状态、账号、数据和生产现场等易变事实必须在相关动作前定点复核。用户确认不能替代可以从代码、Git、测试、服务或环境取得的一手验证。

## 5. 登记、更新与回收

1. 实际文件创建并达到第 4 节最小契约、能够支持至少一个真实复用场景后，才具备登记条件。有项目总览写入授权时，在[项目总览](../项目总览.md)登记唯一主入口、适用范围、维护方、最后核验和刷新触发；没有该授权时只交付建议登记行、依据和尚未写回原因，不把事实文件授权扩大到项目总览。正在调查、阻塞或等待决定的动态过程只进入[当前工作台](../当前工作台.md)。
2. 已有事实文件持续原位更新，不按任务复制新版本；单任务长过程和详细执行证据留在任务主面或任务契约登记的唯一证据/生产记录。新建单次发布或事故记录必须先在任务契约登记文件类型、准确路径、使用者和回收方式，不由运维模板自动决定路径。
3. 事实与代码、Git、测试、服务、环境或有权决定者的新决策冲突时，按[项目文档入口](../00-模板入口.md)核对当前真值；有对应写入授权时只更新受影响事实和核验信息。
4. 主文件过大且已经妨碍定点读取时，可以在同一事实域下拆分专题文件；标准路径仍作为主入口并负责路由专题文件，本索引和项目总览只登记该主入口，不把专题文件并列成多个入口。
5. 移动、删除、合并或拆分文件需要单独授权，并先修正仍然有效的引用；不以“刷新”名义丢弃尚未验收的证据或仍有效的历史。

# 项目总览

本文件是跨任务复用的稳定项目事实，不是默认冷启动材料，也不保存当前任务、实例、阻塞、执行过程或下一步。只有[当前工作台.md](当前工作台.md)已经暴露稳定背景缺口，或当前请求明确需要项目定位、业务边界、项目结构或能力入口时才读取。

模板首次导入时，空白单元格表示“尚无已登记的稳定事实”，不表示项目已初始化、该能力不可用或现场不存在相关事实。用户或有权决定者确认项目价值与业务取舍；代码、Git、测试、配置、数据、服务和环境确认客观现状。未知项保持未知，发生冲突时按[00-模板入口.md](00-模板入口.md)纠偏。

“稳定责任边界”按实际需要标明业务决定者、稳定维护方或两者，不把不同责任含混为一个无标签名称。项目总览不登记默认任务主面、接手动作、当前负责人或智能体实例。当前由谁推进、从哪个任务继续以及下一步是什么，写入[当前工作台.md](当前工作台.md)及其点名的任务主面；项目线内部的详细阅读顺序留在该项目线自己的唯一入口。

## 7. 更新边界

1. 只有跨任务仍会影响目标、边界、结构、入口、稳定决策或术语的变化才更新本文件。
2. 当前状态和执行变化只更新当前工作台或任务主面；能力细节与核验结果只更新对应项目事实文件。
3. 没有本文件写入授权时，只交付已确认变化、证据和建议写回项。
4. 现场事实与本文件冲突时先按现场处理；获得授权后只改受影响字段，并更新来源或确认时间。
5. 删除、移动、合并入口或能力文件需要单独授权，且必须先修正仍然有效的引用。

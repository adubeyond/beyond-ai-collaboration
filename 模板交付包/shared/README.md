# 团队共享区

本目录只保存团队共同依赖的 Markdown：项目登记、团队任务、协同事项及其正式结果。

- `projects/`：业务项目的团队共享登记；
- `tasks/active/`：仍在处理的团队任务；
- `tasks/archive/`：已完成任务的月度精简归档；
- `collaborations/active/`：仍在处理的协同主记录；
- `collaborations/responses/`：各参与者独立维护的结果；
- `collaborations/details/`：确实需要长正文时使用；
- `collaborations/archive/`：已完成协同的月度精简归档。

密码、Token、SSH 私钥、本机绝对路径和个人草稿不得进入本目录。业务代码、补丁和制品继续进入对应业务项目仓。

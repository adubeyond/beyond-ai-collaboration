# 运行事实与部署手册

仅在当前运维动作需要读取、建立或修正服务器、服务、日志、部署和回滚长期事实时读取。普通本地静态预检不进入本文件。

## 1. 定点调查

先从项目或子项目运维入口定位当前环境、服务和发布对象的正式所有者。标为历史、候选、上一阶段或只读追溯的说明不作为当前运行入口；总仓环境总表和子项目 runbook 分别承担其明确范围，不复制成第二份真值。

从部署脚本、CI/CD、服务配置、运行环境和真实服务器现场确认：

- 发布对象、构建方式和制品入口；
- 目标环境、主机、目录、服务和端口；
- 标准部署步骤与前置条件；
- 健康检查、关键业务验证和日志入口；
- 标准回滚锚点、步骤与恢复验证；
- 权限、账号和凭据来源边界，不记录秘密。

可发现事实自行核对。调查后仍缺生产取舍、真实权限或不可发现环境事实时，只问一个会改变安全执行的问题。用户回答不能替代服务器、服务、Git和生产现场核验。

## 2. 写回

稳定服务器和环境事实写回项目事实索引登记的现有环境所有者；可复用发布、观察和回滚路径写回匹配当前子项目、服务和环境的现有 runbook。单次发布或事故结果进入对应任务、发布或运行记录。

没有现成所有者、当前任务确实需要且拥有写入授权时，才按项目事实索引的兜底路径创建最小文件；不复制空模板，不另建初始化任务。

## 3. 复用与变化

后续任务直接复用未变化的环境角色、服务器入口、目录、服务、标准命令、日志和回滚步骤；每次真实运维动作仍需核对目标主机身份，并刷新本次制品、实际运行落点、当前版本、健康状态和授权。旧 IP、旧别名解析或旧核验时间不能单独证明目标仍未变化。

部署脚本、主机、服务、运行时、凭据来源、验证或回滚路径变化时，只更新受影响内容并保留新的核验时间和依据。
